저장하는 정보와 목적

ParkMemo Pro는 사용자가 입력한 차량명, 주차 층·구역, 주차·출차 시각, 위치 변경 내역, 주차장 템플릿과 선택적으로 첨부한 사진을 주차 위치 확인과 기록 관리를 위해 기기에 저장합니다. GPS 위치, 연락처, 광고 식별자를 수집하지 않으며, 계정 가입이나 광고·분석 SDK를 사용하지 않습니다. 개발자 서버로 주차 기록이나 사진을 전송하지 않습니다.

사진과 저장 위치

주차 기록과 사진은 iOS가 관리하는 앱 전용 SwiftData 저장소에 보관합니다. 사진은 앱 전용 저장소의 외부 파일로 보관될 수 있습니다. 카메라는 사진 촬영을 선택할 때 사용하며, 앨범에서는 시스템 사진 선택기로 사용자가 고른 사진만 가져옵니다. 사진은 크기를 줄여 JPEG 사본으로 저장합니다. 앱에서 촬영한 사진을 사진 보관함에 자동으로 저장하지 않으며, 앨범 원본은 변경하거나 삭제하지 않습니다. 카메라 권한은 iOS 설정에서 철회할 수 있습니다. 권한을 철회해도 이미 저장한 사진은 삭제되지 않습니다.

Widget 공유 범위

앱과 함께 제공되는 Widget은 동일 기기의 App Group 공유 저장소를 사용합니다. 현재 주차 중인 차량의 차량명, 층·구역, 주차 시각과 이용권 활성 상태를 공유하며, 사진·완료된 주차 기록·위치 변경 내역·주차장 템플릿은 공유하지 않습니다. 현재 주차 정보나 이용권 상태가 바뀌고 앱이 이를 반영하면 공유 정보를 갱신합니다. 홈 화면 Widget에 표시된 정보는 기기를 보는 사람에게 노출될 수 있습니다. Widget을 홈 화면에서 제거해도 앱의 기록이나 공유 저장소가 삭제되지는 않습니다.

보관과 삭제

기록은 사용자가 삭제할 때까지 보관하며, 출차 완료만으로는 사진이나 기록을 삭제하지 않습니다. 진행 중인 주차의 사진은 사진 삭제로 지울 수 있고, 사진을 변경하면 기존 첨부 사본을 대체합니다. 완료된 주차는 주차 기록 화면에서 개별 삭제하거나 완료 기록 전체 삭제로 사진과 위치 변경 내역을 함께 삭제할 수 있습니다. 현재 주차 중인 기록은 출차 완료 후 삭제할 수 있습니다. 차량과 템플릿은 각 관리 화면에서 삭제할 수 있지만, 마지막 차량이나 주차 중인 차량은 삭제할 수 없으며 차량 삭제만으로 기존 주차 기록이 삭제되지는 않습니다. 출차 후 앱이 공유 정보를 갱신하면 해당 현재 주차 정보는 Widget 공유 데이터에서 빠지며, 실제 Widget 화면 반영 시점은 iOS가 관리합니다. 앱을 완전히 삭제하면 앱 전용 기기 데이터는 제거되지만, 앱 정리하기(Offload)는 데이터를 보존합니다. iOS가 관리하는 공유 데이터와 기존 기기 백업의 보관·삭제는 iOS 설정 및 Apple의 정책을 따릅니다.

백업과 동기화

앱 자체의 서버 백업, iCloud 동기화, 내보내기·복원 기능은 없습니다. 앱은 데이터를 iOS 기기 백업에서 제외하도록 설정하지 않으므로, 사용자의 설정에 따라 iCloud 또는 컴퓨터 기기 백업에 앱 데이터가 포함되고 기기 복원 시 다시 나타날 수 있습니다. 앱에서 삭제해도 기존 백업 사본까지 삭제하지는 않습니다. 백업 관리와 삭제는 iOS 설정 또는 사용하는 컴퓨터에서 진행해야 합니다.

구매와 외부 서비스

평생 이용권 구매·복원은 Apple App Store와 StoreKit을 통해 처리합니다. 앱은 이용권 활성 여부를 확인하며 결제 카드 정보를 직접 받거나 저장하지 않습니다. 공개 정책·지원 페이지를 열면 브라우저와 GitHub Pages 등 해당 서비스의 개인정보 처리방침이 적용됩니다. 문의 이메일을 직접 보내는 경우 선택한 메일 서비스가 이메일 주소와 사용자가 작성·첨부한 내용을 처리합니다. 앱은 주차 기록이나 사진을 문의에 자동 첨부하지 않습니다.
